# Shlack (Slack 클론)

NestJS + TypeORM(MariaDB) + Socket.IO 백엔드와 React 프론트엔드(`front/`)로 구성된 Slack 클론입니다.
API 명세는 [API.md](./API.md) 참고, Swagger 는 서버 실행 후 http://localhost:3002/api 에서 볼 수 있습니다.

## 빠른 실행 (Docker Compose)

MariaDB, Redis, 앱(프론트 포함)을 한 번에 띄웁니다. Docker 가 설치되어 있어야 합니다.

```bash
cp .env.example .env      # SECRET, DB_PW 를 채우세요
docker compose up -d --build
```

http://localhost:3002 접속. 시작할 때 마이그레이션과 기본 워크스페이스(`shlack`) 생성이 자동으로 실행되고,
DB·Redis 데이터는 볼륨에 보존됩니다. 주고받은 파일은 서버에 저장되지 않습니다. 포트를 바꾸려면 `.env` 에 `APP_PORT=8080` 처럼 지정하세요.

아래는 Docker 없이 직접 실행하는 방법입니다.

## 1. 환경 변수 (`.env`)

`.env` 는 비밀번호가 들어가므로 git 에 올리지 않습니다. 예시 파일을 복사해서 값을 채우세요.

```bash
cp .env.example .env
```

| 이름 | 설명 |
|---|---|
| `SECRET` | 세션 쿠키 서명용 비밀값 |
| `DB_USER`, `DB_PW`, `DB_NAME` | MariaDB 접속 정보 (DB 이름 기본 `shlack`) |
| `DB_HOST`, `DB_PORT`, `PORT` | 선택. 기본값 localhost / 3306 / 3002 |
| `REDIS_URL` | 선택. 세션 저장소 (예: `redis://localhost:6379`). 없으면 메모리에 저장되어 서버 재시작 시 로그아웃 |
| `GIPHY_API_KEY` | 선택. GIF 검색용 키 (https://developers.giphy.com 에서 무료 발급) |

## 2. DB 준비 (최초 1회)

MariaDB 설치 및 root 비밀번호 설정 (macOS/Homebrew):

```bash
brew install mariadb
brew services start mariadb
mariadb -e "ALTER USER 'root'@'localhost' IDENTIFIED BY '<원하는 비밀번호>';"   # .env 의 DB_PW 와 같게
```


```bash
npm install
npm run db:setup   # DB 생성 → 마이그레이션 → 기본 워크스페이스(shlack)/채널(일반) 시드
```

개별 실행: `npm run db:create`, `npm run migration:run`, `npm run seed`

처음 가입한 사람이 기본 워크스페이스(`shlack`)의 소유자가 됩니다.

### 스키마 변경 (마이그레이션)

엔티티를 고친 뒤 마이그레이션을 만들고 적용합니다.

```bash
npm run migration:generate   # 엔티티와 DB 차이로 src/migrations/<시각>-Migration.ts 생성
npm run migration:run        # 적용
npm run migration:revert     # 마지막 마이그레이션 되돌리기
```

예전에 `schema:sync` 로 만든 DB 는 데이터를 유지한 채 한 번만 `npm run migration:baseline` 을 실행하세요
(지금 스키마를 초기 마이그레이션이 적용된 상태로 표시합니다).

## 3. 실행

```bash
# 백엔드 (http://localhost:3002)
npm run start:dev

# 프론트엔드 (http://localhost:3090, /api 요청은 3002로 프록시)
cd front
npm install
npm run dev
```

http://localhost:3090 접속 → 회원가입 → 로그인하면 기본 워크스페이스 `shlack` 의 `#일반` 채널로 이동합니다.

## 테스트

```bash
npm test                 # 단위 테스트 (Jest)
npm run test:e2e         # API e2e 테스트 (Jest, .env 의 DB 사용)
```

## 주요 기능

- 회원가입/로그인, 워크스페이스·채널 생성 및 초대, DM, 이미지 업로드(드래그 앤 드롭)
- 실시간 채팅, 온라인 표시, 안 읽은 메시지 수
- Mattermost 기능 대응
  - 메시지 수정/삭제 (채널, DM) · `(수정됨)` 표시
  - 이모지 리액션 (채널 메시지)
  - 스레드 답글 (오른쪽 스레드 패널)
  - 메시지 고정 (📌 고정 목록 패널)
  - 메시지 검색 (상단 검색창, 채널 + DM) · 결과를 누르면 그 메시지 위치로 이동해 강조 (스레드 답글은 스레드를 열어서)
  - 마크다운: `**굵게**`, `*기울임*`, `~~취소선~~`, `` `코드` ``, ```` ``` ```` 코드 블록, `>` 인용, `[링크](https://...)`, 주소 자동 링크
  - 프로필 설정 (프로필 메뉴): 닉네임, 프로필 그림 모양, 비밀번호 변경
  - 메시지 더 다루기
    - 메시지 링크 복사(🔗): 붙여넣으면 `🔗 메시지 링크`로 보이고 누르면 그 메시지로 이동
    - 저장한 메시지(🔖): 나중에 볼 메시지를 저장하고 상단 🔖 에서 모아 보기
    - 쓰다 만 메시지는 채널/DM 별로 임시 저장 (사이드바에 ✏️)
    - `@channel`(채널 멤버 모두), `@here`(접속 중인 멤버) 멘션
    - 사용자 그룹 멘션: 워크스페이스 메뉴 `사용자 그룹` 에서 그룹을 만들고 `@그룹이름` 으로 멘션 (그룹 멤버 중 채널 멤버에게 알림)
    - DM 에서도 리액션과 메시지 고정
  - 채널·워크스페이스 관리
    - 채널 설정(⚙): 주제(멤버 누구나), 이름 변경·보관(읽기 전용)·삭제(채널을 만든 사람·워크스페이스 소유자)
    - 워크스페이스 설정(소유자): 이름·주소 변경(접속 중인 멤버도 새 주소로 이동), 소유권 넘기기
  - 이동·읽기 편의
    - 빠른 이동 `Ctrl/⌘ + K`: 채널·사람 이름으로 바로 이동
    - 채널/DM 에 들어가면 안 읽은 첫 메시지 위에 `새 메시지` 구분선, 그 위치로 스크롤
    - 스레드 모아 보기(🧵): 내가 참여한 스레드를 최근 답글 순으로, 새 답글 수 표시
    - 단축키: 빈 입력창에서 `↑` 내 마지막 메시지 수정, `Esc` 패널 닫기, `Ctrl/⌘ + /` 단축키 목록
  - 메시지 수정 내역: `(수정됨)` 을 누르면 처음 내용부터 지금까지 보기
  - DM 읽음 표시: 상대가 읽은 내 마지막 메시지 아래에 `✓ 읽음`
  - 메시지 도구
    - 예약 전송(입력창 `🕒 예약`): 정한 시각에 서버가 대신 보냄, 입력창 위에서 예약 목록 보기·취소
    - 리마인더(메시지 ⏰): 정한 시각에 그 메시지를 다시 알림. 접속해 있지 않으면 이메일로 알리고(`SMTP_URL` 설정 시) 다음 접속 때 앱에서도 알림
    - 투표(입력창 `📊 투표`): 선택지 번호 이모지로 투표, 득표 막대 표시, `하나만 고르기` 옵션, 올린 사람이 `투표 마감`
    - 검색 필터(채널·보낸 사람·기간 — 기간은 내 시간대 기준)와 `더 보기`
  - 알림·상태
    - 탭 제목에 안 읽은 수 표시 `(3) 슐랙`
    - 멘션/DM 데스크톱 알림 (누르면 그 메시지로 이동), 프로필 메뉴에서 일시 중지/다시 켜기
    - 채널 알림 끄기 (채널 상단 `🔔 알림`): 안 읽은 표시를 숨기고 멘션만 알림
    - 상태 메시지 (예: 🗓️ 회의 중)와 자리 비움 표시 (프로필 메뉴)
  - 입력 중 표시 (채널, DM)
  - 채널 나가기 (`#일반` 제외)
  - 공개/비공개 채널: 공개 채널은 `채널 둘러보기`에서 직접 참여, 🔒 비공개 채널은 초대받은 사람만 보고 참여
  - GIF 검색해서 보내기 (GIPHY, `GIPHY_API_KEY` 필요)
  - 파일 주고받기 (모든 형식, 20MB 이하): 서버에 저장하지 않고 접속 중인 상대에게 중계, 각자 기기(브라우저 저장소)에 보관 · `기기에 저장` 버튼
    - 보낼 때 오프라인이던 사람은 나중에 파일을 열면 접속 중인 보낸 사람의 기기에서 다시 받아옵니다 (서버는 중계만)
    - 프로필 메뉴 `이 기기의 파일`: 저장된 파일 목록·용량, 선택/오래된 파일 지우기
    - 보내기 진행률 표시, 이미지 크게 보기
- 허들(1:1 통화): DM 상단 `📞 통화` 로 음성 통화, 통화 중 화면 공유·음소거
  - 신호만 소켓으로 서버가 중계하고 음성·화면은 WebRTC 로 두 브라우저가 직접 주고받음
  - 같은 네트워크가 아니면 TURN 서버가 필요할 수 있음 (`.env` 의 `TURN_URL` 등)
- 이모지
  - 이모지 고르기: 입력창 😀, 리액션 ＋ 에서 전체 이모지를 한국어로 검색(예: 엄지, 하트), 최근 쓴 이모지
  - 커스텀 이모지: 워크스페이스 메뉴 `커스텀 이모지` 에서 그림을 올리고 `:이름:` 으로 메시지·리액션에 사용 (작은 그림만 DB 에 저장)
- 연동
  - 슬래시 명령: `/remind 30분 회의 준비`, `/poll 점심? | 국밥 | 짜장`, `/status 🗓️ 회의 중`, `/away`, `/back`, `/topic`, `/mute`, `/unmute`, `/shrug`, `/help` (입력창에 `/` 를 치면 목록)
  - 수신 웹훅: 채널 설정에서 주소를 만들고, 외부 서비스가 `POST /api/hooks/:token` 에 `{"text": "..."}` 를 보내면 채널에 앱 메시지로 올라옴
    ```bash
    curl -X POST -H 'Content-Type: application/json' -d '{"text":"배포가 끝났습니다 🚀"}' http://localhost:3002/api/hooks/<토큰>
    ```
- 기기 간 동기화: 어디까지 읽었는지(채널·DM·스레드), 쓰다 만 메시지, 화면 테마·알림 일시 중지를 계정에 저장해 어느 기기에서나 같게 (다른 기기에서 읽으면 바로 반영)
- Docs (왼쪽 메뉴 `Docs`): 슐랙 안에서 쓰는 문서·위키·슬라이드·스프레드시트. 내용은 글(마크다운·JSON)로 DB 에 저장하고 pptx·xlsx·hwp 같은 파일은 다루지 않음
  - 홈: `최근` / `내 소유` / `나와 공유한 파일` / `즐겨찾기` 탭, 목록·격자 보기, 제목 검색, 템플릿(회의록, 주간 보고, 기술 문서, 발표 슬라이드, 예산표, 할 일 관리표, 팀 위키)
  - 문서: 마크다운 편집 (제목, 표, 할 일 목록, 코드 블록, 이미지 주소, 인용 …) · `편집 / 나란히 / 보기` · 1초 뒤 자동 저장 · 보기에서 목차
  - 슬라이드 (파워포인트처럼)
    - 쪽: 레이아웃(제목 / 제목 + 내용 / 두 칸 / 빈 쪽), 끌어서 순서 바꾸기, 복제·지우기, 숨기기(발표에서 건너뜀), 배경색·테마, 전환 효과(밝아지기·밀어내기·확대), 발표자 메모
    - 요소: 글상자, 도형 14가지(사각형·원·별·말풍선·화살표·육각형 …), 그림(파일·https 주소), 표, 차트(막대·꺾은선·영역·원형)
    - 편집: 끌어 옮기기·크기 조절·회전(Shift 로 15도씩), 빈 곳을 끌어 여러 개 고르기·Shift 로 더 고르기, 스마트 가이드(다른 요소·쪽 가운데에 맞춤), 맞춤·간격 같게, 앞/뒤 순서, 복사·붙여넣기·복제, 오른쪽 클릭 메뉴, 확대/축소, 되돌리기
    - 꾸미기: 글꼴·크기·굵게·기울임·밑줄·취소선·정렬·줄 간격·글자색, 채우기·선 색·굵기·파선/점선, 모서리, 투명도, 그림자
    - 발표: 전체 화면, 요소 애니메이션(누를 때마다 나타나기), 발표자 보기(메모·타이머·다음 쪽, P 키), PDF 로 저장(인쇄)
    - 그림은 https 주소로 넣거나, 올린 그림을 가로 1024px JPEG 로 줄여 문서 안에 저장 (한 문서 약 900KB 까지). 예전 마크다운(`---`) 슬라이드는 열 때 글상자로 바뀜
  - 스프레드시트 (엑셀처럼)
    - 입력: 칸을 고르고 바로 입력(한글 포함), Enter/Tab/방향키 이동, 수식 입력줄, 이름 상자로 이동, 수식 쓰는 중 칸을 누르면 주소 넣기, 함수 이름 추천
    - 함수 70여 개: SUM·AVERAGE·COUNT·MIN·MAX·ROUND 계열, SUMIF(S)·COUNTIF(S)·AVERAGEIF(S), IF·IFS·IFERROR·AND·OR, VLOOKUP·HLOOKUP·XLOOKUP·INDEX·MATCH, 날짜(TODAY·DATE·YEAR·EOMONTH·NETWORKDAYS …), 글자(LEFT·MID·SUBSTITUTE·TEXT·TEXTJOIN …)
    - 채우기 핸들(숫자 간격·날짜·수식 이어 채우기), Ctrl+D/R, 복사·붙여넣기(엑셀·구글 시트와 탭으로 나눈 글), 잘라내기
    - 서식: 굵게·기울임·밑줄·취소선·글자 크기·색·채우기·테두리·정렬·줄 바꿈, 숫자·원화·퍼센트·날짜·글자 형식, 소수 자릿수, 셀 병합, 조건부 서식(크다·작다·사이·포함·상위 N·색 눈금)
    - 데이터: 정렬(머리글 자동 인식), 필터(값 고르기), 드롭다운 목록(데이터 확인), 칸 메모, 찾기·바꾸기
    - 보기: 틀 고정, 행·열 넣기·지우기·숨기기, 행 높이·열 너비 끌기, 시트 탭(복제·순서·색), 차트(끌어 옮기기·크기 조절), 고른 칸 합계·평균·개수, CSV 가져오기·내보내기, 되돌리기
  - 위키: 워크스페이스 모두가 보고 고치는 페이지 트리 (하위 페이지, 경로 표시)
  - 공유: 기본은 `🔒 나와 공유한 사람만`, 사람마다 `보기만 / 고칠 수 있음`, 또는 `워크스페이스 모두`. 공유받으면 알림
  - 함께 고치기: 다른 사람이 먼저 저장하면 고친 게 없을 때는 바로 반영, 고치는 중이면 `최신 내용 불러오기 / 내 내용으로 덮어쓰기` 를 고름 (버전 번호로 덮어쓰기 방지)
  - 정리: 내 문서 라이브러리의 폴더(하위 폴더), 왼쪽 목록에 고정(☆), 휴지통(되살리기 · 완전히 지우기)
- 캘린더 (왼쪽 메뉴 `캘린더`)
  - 일·주·월 보기, 작은 달력, 빈 칸을 누르면 그 시각에 일정 만들기, 겹치는 일정은 나란히
  - 일정: 제목, 시작·끝(종일), 장소, 설명, 색, 참석자, 알림(시작할 때 ~ 1주 전), 공개/🔒 비공개(참석자 외에는 `바쁨`)
  - 참석자는 `✅ 참석 / ❌ 불참` 으로 답하고, 주최자만 고치거나 지움
  - 동료 캘린더 구독: 동료 일정을 내 캘린더에 겹쳐 보기 (캘린더마다 색, 켜고 끄기)
  - 캘린더 어시스턴트 봇: 초대·변경·취소·참석 응답·시작 전 알림을 DM 으로 보냄 (메신저 DM 목록에 봇 대화). 접속해 있지 않으면 이메일로도 (`SMTP_URL` 설정 시)
    - 봇은 서버가 켜질 때 자동으로 만들어져 모든 워크스페이스에 들어가며, 로그인할 수 없음
    - 봇 메시지 시각은 `APP_TZ`(기본 `Asia/Seoul`) 기준
- 화면
  - 왼쪽 메뉴: `메신저`, `Docs`, `캘린더` 사이를 오감 (메신저로 돌아오면 보던 채널·DM). 화면의 아이콘은 SVG (lucide-react)
  - 다크 모드: 프로필 메뉴 `🌓 화면 테마` (시스템 설정 따르기 / 라이트 / 다크)
  - 휴대폰 화면: ☰ 로 채널 목록 서랍, 스레드·고정 패널은 전체 화면, Docs 는 위쪽 메뉴로 이동
- 보안
  - 소켓도 로그인 세션으로 사용자를 확인하고, 참여 중인 채널 방에만 들어간다
  - 채널 API는 채널 멤버만 사용 가능 (비공개 채널은 비멤버에게 404)
  - 보안 헤더(helmet, CSP), 허용한 출처만 CORS, 다른 사이트에서의 소켓 연결 거부, 로그인 쿠키 SameSite=Lax
  - 요청 수 제한: IP 당 1분 600회, 로그인·회원가입·비밀번호 변경은 1분 10회 (`.env.example` 참고)

> 이미 DB를 만들어 둔 상태에서 업데이트했다면 `npm run migration:run` 으로 새 마이그레이션을 반영하세요.

## 구조

- `src/users` 회원가입/로그인/로그아웃 (passport-local + express-session), 프로필·비밀번호 변경
- `src/workspaces` 워크스페이스 생성, 멤버 조회/초대/강퇴
- `src/channels` 채널 생성/조회, 채팅, 이미지 업로드, 안 읽은 메시지 수
- `src/dms` DM 채팅, 이미지 업로드, 안 읽은 메시지 수
- `src/search` 메시지 검색 (채널 + DM, 채널·보낸 사람·기간 필터, 페이지)
- `src/scheduled` 예약 전송·리마인더 (15초마다 시각이 된 것을 처리)
- `src/gifs` GIF 검색 (GIPHY 프록시, API 키는 서버에만 보관)
- `src/calendar` 일정·참석 응답·동료 캘린더 구독, 15초마다 시작 전 알림 (`calendarevents` / `calendarattendees` / `calendarfollows`)
- `src/bots` 봇 계정 (캘린더 어시스턴트) 준비, 봇에게 보낸 DM 에 안내 답장
- `src/docs` 문서·위키·슬라이드 (`docs` / `docfolders` / `docshares` / `docuserstates` 테이블, 저장은 `version` 으로 낙관적 잠금)
- `src/events` Socket.IO 게이트웨이 (`/ws-{워크스페이스url}` 네임스페이스, `login`/`onlineList`/`message`/`dm`/`typing` 등)
- 파일은 서버에 저장하지 않습니다. 서버는 받은 파일을 접속 중인 상대에게 중계만 하고, 각자의 브라우저 저장소(IndexedDB)에 보관됩니다.
